# Open-Source Grant / Bounty Evaluation Rubric

Score each dimension 1–5. Publish the rubric before applications close.

| Dimension | What a 5 looks like | Weight |
|---|---|---:|
| Ecosystem value | Solves a repeated, high-impact developer/resource gap | 25% |
| Feasibility | Scope, milestones and dependencies are credible | 20% |
| Maintainability | Clear ownership, tests, docs and handoff plan | 15% |
| Openness | Reusable output with an appropriate OSS/data license | 15% |
| Developer experience | Reduces time/friction for downstream builders | 15% |
| Trust & domain care | Strong provenance, correctness and review practices | 10% |

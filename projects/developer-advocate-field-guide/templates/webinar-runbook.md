# Developer Webinar Runbook

## Outcome
What should a developer be able to build by the end?

## 7 days before
- Confirm runnable repository
- Test clean setup
- Publish prerequisites
- Collect questions

## Session (45–60 min)
1. Problem/context — 5 min
2. Live build — 25 min
3. Architecture + trade-offs — 10 min
4. Q&A — 15 min
5. Contribution / next step — 5 min

## After
- Publish recording + code + links
- Convert unanswered questions to docs/issues
- Tag roadmap signals
- Thank/recognize community contributions
